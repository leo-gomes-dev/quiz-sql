Desenvolvido para revisão em grupo — Teste seus conhecimentos antes da prova!

Questão 01

Qual é o mecanismo principal que causa a vulnerabilidade de SQL Injection em uma aplicação?

Explicação: O problema acontece quando o código apenas "cola" o texto do usuário no meio da query SQL. O banco de dados não sabe onde termina o dado e onde começa o comando, permitindo que as aspas simples `'` alterem a estrutura da consulta.

Questão 02

O que o caractere de comentário (como `--` no SQLite) permite que um invasor faça ao injetar código?

Explicação: Ao injetar `--` logo após o nome do usuário (ex: `admin' --`), tudo o que vier depois na linha do código SQL original (como a verificação `AND senha = ?`) vira um mero comentário e é ignorado pelo banco, aprovando o login sem senha.

Questão 03

Por que o uso de "Prepared Statements" (com interrogações `?`) resolve essa falha de segurança?

Explicação: Com comandos parametrizados (`?`), o formato da busca já está pré-definido pelo banco. Se o invasor digitar comandos SQL nas caixas de texto, o banco vai apenas procurar por um registro que contenha literalmente aquele texto esquisito escrito na tabela.
